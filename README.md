# Disk Ledger

システム設定で「システムデータ」とまとめて表示される容量の中身を、キャッシュ、ログ、アプリの補助データ、開発ツールなどの種類に分けて見せる Mac アプリです。種類ごとに「消しても作り直される」「消すと戻せない」といった目安を出し、中のフォルダを開いて、どのアプリのものかを確かめられます。仕様は [docs/仕様書.md](docs/仕様書.md) にあります。

## 作り方

```bash
scripts/bundle.sh
```

`build/Disk Ledger.app` ができます。初めて開くとフルディスクアクセスを求めるので、システム設定で許可してから開き直します。ローカル署名なので、作り直すたびに許可し直す必要があります。

## 確認用の道具

- `swift test` 走査、分類、ボリュームの使用量のテスト
- `swift run -c release ledger-scan <パス>` 画面を通さずに走査し、所要時間と大きい項目を出す。パスを省くとディスク全体を読むが、フルディスクアクセスのない端末から動かすと許可を求める窓が多数出る
- アプリの起動引数 `--scan-root <パス>` で指定した場所だけを読み、`--snapshot <PNG>` で読み終えたウィンドウを PNG に描き出して終了する。描き出しでは左の一覧と見出しの背景が写らない
